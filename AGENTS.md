# TCalc

Rules for AI assistants working on this repository are in [CLAUDE.md](CLAUDE.md) and the topic files under [docs/rules/ai/](docs/rules/ai/). Read `CLAUDE.md` first; it applies to every assistant, not only Claude. Its `@path` lines are imports: read each of those files once at the start of the session.

The hookify rules under `.claude/` are enforced only in Claude Code. In other tools, follow the same rules by hand.
