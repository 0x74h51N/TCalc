# Security Policy

## Supported Versions

Only the latest release receives security fixes.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public issues.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/0x74h51N/TCalc/security/advisories/new), with the steps to reproduce and the version affected.

TCalc is maintained in spare time. Reports are handled on a best-effort basis, with no guaranteed response time and no warranty, as stated in the [license](../LICENSE).
